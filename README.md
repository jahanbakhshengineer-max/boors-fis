# تحلیل بنیادی سهام — راه‌اندازی روی گیت‌هاب و نصب مثل یک برنامه

## فایل‌های این پوشه
- `index.html` — خودِ برنامه (باید همیشه دقیقاً همین اسم بمونه: `index.html`)
- `manifest.json` — مشخصات برنامه برای نصب (اسم، آیکون، رنگ)
- `sw.js` — سرویس‌ورکر؛ باعث می‌شه برنامه به‌صورت آفلاین هم باز بشه و مثل اپ نصب بشه
- `icon-192.png`, `icon-512.png` — آیکون برنامه

## مرحله ۱ — ساخت مخزن (Repository) روی گیت‌هاب
1. وارد github.com شو و وارد حساب کاربری‌ت بشو (اگه نداری، رایگان بساز).
2. دکمه‌ی سبز «New» (یا «+» بالای صفحه → New repository) رو بزن.
3. یه اسم بذار، مثلاً `boors-fundamental-analyzer`.
4. گزینه‌ی Public رو انتخاب کن (برای GitHub Pages رایگان لازمه پابلیک باشه، مگه اکانت پولی داشته باشی).
5. «Create repository» رو بزن.

## مرحله ۲ — آپلود فایل‌ها
1. توی صفحه‌ی مخزن تازه‌ساخته‌شده، روی «uploading an existing file» کلیک کن.
2. هر ۵ فایل این پوشه (`index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`) رو بکش و بنداز.
3. پایین صفحه «Commit changes» رو بزن.

## مرحله ۳ — فعال‌سازی GitHub Pages
1. توی همون مخزن برو تب «Settings».
2. از منوی سمت چپ «Pages» رو بزن.
3. زیر «Build and deployment» → «Source» رو بذار روی «Deploy from a branch».
4. Branch رو بذار روی `main` و پوشه رو `/ (root)`، بعد «Save».
5. چند دقیقه صبر کن؛ آدرس سایتت این شکلی می‌شه:
   `https://USERNAME.github.io/boors-fundamental-analyzer/`
   (به‌جای USERNAME اسم کاربری گیت‌هابت رو بذار)

## مرحله ۴ — نصب مثل یک برنامه

### روی ویندوز (با گوگل کروم یا مایکروسافت اج)
1. آدرس سایت رو باز کن.
2. سمت راست نوار آدرس، آیکون «نصب» (یه علامت شبیه مانیتور با فلش) رو بزن — یا از منوی سه‌نقطه → «Install app…» / «نصب برنامه…».
3. برنامه به‌صورت یه پنجره‌ی جدا (بدون نوار آدرس مرورگر) روی دسکتاپ/منوی استارت نصب می‌شه.

### روی گوشی اندروید (کروم)
1. آدرس سایت رو باز کن.
2. منوی سه‌نقطه بالا سمت راست → «Add to Home screen» / «افزودن به صفحه‌ی اصلی».
3. آیکون برنامه روی صفحه‌ی اصلی گوشی می‌شینه و مثل یک اپ عادی باز می‌شه.

### روی آیفون (سافاری)
1. آدرس سایت رو باز کن.
2. دکمه‌ی Share (مربع با فلش رو به بالا) → «Add to Home Screen».

## مرحله ۵ — آپدیت کردن نسخه‌ی جدید
هر وقت نسخه‌ی جدید `index.html` رو گرفتی:
1. برو توی مخزن گیت‌هابت، روی فایل `index.html` کلیک کن.
2. آیکون مداد (Edit) رو بزن، محتوای قدیمی رو پاک کن، محتوای جدید رو پیست کن — یا ساده‌تر: از «Add file → Upload files» فایل جدید رو با همون اسم `index.html` آپلود کن تا جایگزین بشه.
3. پایین صفحه «Commit changes» بزن.
4. تا ۱-۲ دقیقه بعد، هم نسخه‌ی وب و هم نسخه‌ی نصب‌شده (که سرویس‌ورکر همیشه اول از اینترنت آخرین نسخه رو می‌گیره) خودکار به‌روز می‌شن — کاربر فقط کافیه یه بار برنامه رو ببنده و دوباره باز کنه.

نکته: اگه به `manifest.json`, `sw.js` یا آیکون‌ها هم تغییری دادم، همونا رو هم با همین روش جایگزین کن؛ در غیر این صورت فقط کافیه `index.html` رو عوض کنی.

## نکته درباره‌ی ذخیره‌سازی اطلاعات
اطلاعات برنامه (سهم‌ها، صورت‌های مالی و ...) با `localStorage` توی همون مرورگر/دستگاهی که ازش استفاده می‌کنی ذخیره می‌شه — نه روی گیت‌هاب. برای بک‌آپ دستی، از قابلیت «بکاپ» خودِ برنامه (خروجی/ورودی JSON) استفاده کن.

## همگام‌سازی خودکار با گیت‌هاب (اختیاری)
توی تب «پشتیبان‌گیری و بازیابی»، بخش «همگام‌سازی با گیت‌هاب» رو پیدا کن. با این قابلیت می‌تونی اطلاعاتت رو مستقیم توی یه فایل داخل همین مخزن گیت‌هابت ذخیره/بازیابی کنی تا بین گوشی و کامپیوتر sync بشه:

1. یه **Personal Access Token** بساز: گیت‌هاب → عکس پروفایل → Settings → پایین صفحه «Developer settings» → «Personal access tokens» → «Fine-grained tokens» → «Generate new token».
2. زیر «Repository access» فقط همین یه مخزن (`boors-fundamental-analyzer` یا هر اسمی که گذاشتی) رو انتخاب کن، نه «All repositories».
3. زیر «Permissions» → «Repository permissions» → «Contents» رو بذار روی **Read and write**.
4. توکن ساخته‌شده (با `ghp_` یا `github_pat_` شروع می‌شه) رو کپی کن — فقط یه‌بار نشونت می‌ده.
5. توی برنامه، همون توکن + نام کاربری + نام مخزن رو وارد کن و «ذخیره تنظیمات» بزن.
6. با «⬆️ ذخیره در گیت‌هاب» اطلاعات فعلی رو می‌فرستی؛ با «⬇️ دریافت از گیت‌هاب» آخرین نسخه‌ی ذخیره‌شده رو می‌گیری (جای‌گزین اطلاعات فعلی مرورگر می‌شه).

⚠️ نکات امنیتی و عملی:
- توکن فقط توی همون مرورگر (localStorage) نگه داشته می‌شه و هیچ‌وقت داخل فایل‌های بک‌آپ دانلودی قرار نمی‌گیره؛ ولی اگه از یه کامپیوتر مشترک/عمومی استفاده می‌کنی، بعد از کارت توکن رو از تنظیمات پاک کن.
- هر بار «ذخیره در گیت‌هاب» یعنی یه commit جدید توی مخزن — بهتره فقط وقتی داده‌ی مهمی عوض شده این کار رو بزنی، نه با هر تغییر کوچیک.
- sync آنی نیست: اگه هم‌زمان از دو دستگاه استفاده کنی و هر دو رو بدون sync ویرایش کنی، آخرین «ذخیره» نسخه‌ی قبلی رو overwrite می‌کنه. همیشه قبل از ویرایش روی دستگاه جدید، یه «دریافت از گیت‌هاب» بزن.
